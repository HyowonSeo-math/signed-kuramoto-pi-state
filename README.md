# Frequency Synchronization of Signed Kuramoto Networks via a π-State Transformation

**Authors:** Sun-Ho Choi and Hyowon Seo  
**Software:** MATLAB  
**Manuscript:** *Frequency synchronization of signed Kuramoto networks via a π-state transformation*

This repository contains the MATLAB implementation of the numerical experiments in **Section IV** of the manuscript. The simulations examine exponential frequency synchronization in directed, weighted conformist–contrarian Kuramoto networks, the sufficient conditions in **Theorem II.1**, and the effects of coupling gain, network structure, and initial phases.

## Contents

- **[`run_signed_kuramoto.m`](run_signed_kuramoto.m):** Simulation and figure-generation code.
- **[`FIGURES.md`](FIGURES.md):** Experiment descriptions, parameter settings, and generated filenames.

## Getting started

Download or clone this repository, and open the extracted directory in MATLAB. **Do not run the MATLAB file from inside a ZIP archive or a temporary extraction directory.**

### 1. Check the implementation

```matlab
run_signed_kuramoto('selftest');
```

### 2. Run a short trial

```matlab
[results, outdir] = run_signed_kuramoto('quick', [], struct('Visible','off'));
```

### 3. Run the full experiments

```matlab
[results, outdir] = run_signed_kuramoto('full', [], struct('Visible','off'));
```

The `full` mode uses the manuscript trial counts and may require considerable computation time and storage. The `quick` mode reduces the number of trials and is intended for an initial execution check; it does **not** reproduce the full statistical summaries.

## Mathematical model

The dynamics are

```math
\dot{\theta}_i = \omega_i + \frac{K}{N}s_i\sum_{j=1}^{N}a_{ij}\sin(\theta_j-\theta_i), \qquad s_i\in\{-1,+1\}.
```

Here, `a(i,j)` is the nonnegative coupling weight **from oscillator `j` to oscillator `i`**. The π-state transformation is

```math
\widetilde{\theta}_i(t)=\theta_i(t)-\frac{1-s_i}{2}\pi-\bar{\omega}t,
\qquad \bar{\omega}=\frac{1}{N}\sum_{i=1}^{N}\omega_i.
```

In MATLAB, the signed source-weight matrix is assembled as `B = A * diag(s)`. In the transformed dynamics, conformist sources contribute attraction and contrarian sources contribute repulsion.

**Phase-diameter convention:** The code measures the diameter using continuous, real-valued, **unwrapped** transformed phases. These are not replaced by principal-angle differences modulo `2*pi`.

## Numerical settings

- **ODE solver:** MATLAB `ode45`
- **Relative tolerance:** `1e-9`
- **Absolute tolerance:** `1e-11`
- **Default random seed:** `20261010`
- **Maximum simulation time:** `100`
- **Numerical synchronization threshold:** frequency diameter no greater than `1e-6` over a trailing window of `5` time units; the test begins after time `20`.

**Interpretation:** The analytical criterion is sufficient, not necessary. Failure to meet the numerical threshold before the final time is recorded as a finite-horizon unresolved trial; it is not proof of non-synchronization.

## Output files

By default, the program saves results under the user's home directory:

```text
signed_kuramoto_results/results_signed_kuramoto_<mode>_<timestamp>/
```

To choose the output directory explicitly:

```matlab
outdir = fullfile(getenv('USERPROFILE'), 'signed_kuramoto_results', ...
    ['full_' datestr(now,'yyyymmdd_HHMMSS')]);
[results, outdir] = run_signed_kuramoto('full', outdir, struct('Visible','off'));
```

**Typical output files**

- `configuration.mat` — MATLAB version and simulation settings.
- `results.mat` — experiment records and numerical summaries.
- `trials/*.mat` — network weights, sampled frequencies, initial phases, and trial data.
- `*_trials.csv`, `*_summary.csv` — trial records and summary statistics.
- `.fig`, `.pdf`, `.eps`, `.png` — figure files produced by the selected experiments.

To regenerate supported figures from previously saved results:

```matlab
run_signed_kuramoto('replot', 'PATH_TO_PREVIOUS_RESULTS', struct('Visible','off'));
```

The code does not overwrite a directory containing an existing `results.mat` file. Some manuscript panels are exported as separate figure files. The automatically selected illustration for Figure 3 may not match the specific realization in the published figure; see [FIGURES.md](FIGURES.md).

## Requirements and reproducibility

MATLAB with `ode45`, `tiledlayout`, `exportgraphics`, and `savefig` is required. No additional MATLAB toolboxes are needed by the source code. Compatibility with older MATLAB releases and GNU Octave has not been established.

The program retains random seeds and sampled inputs. The source package has not been run through a complete MATLAB replication of every figure and table in this preparation environment; the numerical results should be verified using MATLAB before public release.
